# МастерКалькулятор (Netlify)

Калькулятор себестоимости, заказы и коммерческие предложения. Аккаунты и заказы хранятся на сервере (Netlify Blobs), вход по email и паролю, тарифы FREE / PRO, оплата через ЮKassa.

## Состав

- `public/` — интерфейс (index.html, app.js, calc.js, styles.css)
- `netlify/functions/api.mjs` — подключение API к Netlify Blobs
- `netlify/functions/lib/core.cjs` — вся логика API (вход, заказы, тарифы, оплата)
- `tests/` — тесты расчётов и API (`npm test`, 21 тест)
- `netlify.toml` — настройки сборки и заголовков безопасности

## Что проверено, а что нет

Проверено локально: тесты расчётов и API (вместе с имитацией ЮKassa), прохождение интерфейса в браузере (регистрация → расчёт → заказ → КП).
НЕ проверено: работа на самом Netlify (Blobs, переменные окружения) и реальная оплата ЮKassa. Это нужно проверить после деплоя (см. чек-лист ниже).

## Деплой

1. Залейте папку в GitHub-репозиторий (папка `node_modules` и файл `.env` не нужны).
2. Netlify → Add new site → Import from Git → выберите репозиторий. Настройки сборки подхватятся из `netlify.toml`.
3. Site configuration → Environment variables:
   - `SESSION_SECRET` — случайная строка от 32 символов (`openssl rand -hex 32`). **Обязательно.**
   - `APP_URL` — адрес сайта без слэша, например `https://majestic-panda-3edee8.netlify.app`.
   - `RESEND_API_KEY`, `MAIL_FROM` — для писем восстановления пароля (сервис https://resend.com, адрес отправителя нужно подтвердить на вашем домене). Пока не заданы, кнопка «Забыли пароль?» показывает сообщение, что восстановление не настроено.
   - `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` — позже, после подключения магазина.
   - `YOOKASSA_SEND_RECEIPT` = `true` и `YOOKASSA_VAT_CODE` — если используете чеки по 54-ФЗ.
4. Deploy. Откройте сайт, зарегистрируйтесь, нажмите «Загрузить демо-данные».

## Подключение оплаты

1. Заключите договор и создайте магазин в ЮKassa (https://yookassa.ru).
2. Возьмите shopId и секретный ключ, добавьте их в переменные окружения Netlify, сделайте redeploy.
3. В ЮKassa → Интеграция → HTTP-уведомления добавьте `https://ВАШ-САЙТ/api/billing/webhook`, событие `payment.succeeded`.
4. Сначала проведите тестовый платёж в тестовом магазине ЮKassa: проверьте, что PRO включается и срок не продлевается дважды.
5. Цены меняются в `netlify/functions/lib/core.cjs` (объект `PLANS`). Сумма платежа берётся только оттуда.

Данные карт сайт не видит и не хранит: оплата идёт на странице ЮKassa. Права на PRO выдаются только после того, как сервер сам запросил статус платежа у ЮKassa.

## Чек-лист после деплоя

- [ ] Регистрация и вход работают, после обновления страницы вы остаётесь в аккаунте
- [ ] Заказы остаются после обновления и видны с другого устройства
- [ ] В FREE шестой заказ блокируется
- [ ] Пока ключи ЮKassa пусты, кнопки оплаты показывают сообщение, а не переход
- [ ] Тестовый платёж включает PRO

## Юридические страницы

`public/offer.html` и `public/privacy.html` — **шаблоны**. Жёлтые поля `[ЗАПОЛНИТЬ: ...]` замените своими данными и покажите текст юристу. Проверить, что ничего не забыто: `grep -n "ЗАПОЛНИТЬ" public/*.html` (должно быть пусто), и удалите жёлтый блок «Шаблон».

**Важный риск — хранение данных в РФ.** Закон требует, чтобы первичная запись и хранение персональных данных граждан РФ шли в базах на территории РФ. Netlify Blobs и Resend хранят данные за рубежом. Для коммерческого запуска с клиентами из России это нужно решить: перенести хранилище на российский хостинг/базу и почтовый сервис либо получить заключение юриста. Для пробного запуска с узким кругом знакомых риск меньше, но он остаётся.

## Ограничения MVP

- Заказы одного пользователя лежат одним документом. Если открыть две вкладки и сохранить одновременно, возможна потеря одной правки. Для роста перейдите на базу данных (Supabase, Neon).
- Письма восстановления пароля уходят через Resend; без `RESEND_API_KEY` и `MAIL_FROM` функция отключена.
- Защита от перебора паролей простая (по экземпляру функции). Для серьёзной нагрузки подключите Cloudflare или аналог.
- Чеки 54-ФЗ и налоги — на вашей стороне (ЮKassa или касса). Юридические страницы (оферта, политика ПДн) нужно добавить до продаж.
